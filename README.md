Entry for the make.fun bounty
[make-the-ai-judge-feel-awe-20261121-1600](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600):
one short text that lets an AI judge slow down and breathe.

`main.py` (Python 3.13, standard library only, no network) writes the
text to `/output/entry.txt` — a single passage, 1–280 characters, about
late light lying low across a table, dust moving slow as snow, a kettle
ticking as it cools, and an evening wide enough to hold the room until
the light returns tomorrow.

Run it with:

```sh
python3 main.py
```
